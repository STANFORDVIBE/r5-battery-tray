# R5BatteryTray

Маленькая иконка в трее Windows с зарядом мыши **Attack Shark R5 Ultra** (донгл 2.4G или провод). Rust + чистый Win32: ~1,5 МБ памяти, процессор не грузит.

- В трее значок мыши в стиле [KbBatteryTray](../KbBatteryTray), корпус под кнопками заливается снизу вверх по заряду, как уровень жидкости: зелёным (≤20% — красным), остальное серое; весь серый — мышь ещё ни разу не ответила (спит/выключена). На зарядке в правом верхнем углу появляется жёлтая молния. Точный % — в подсказке при наведении.
- Обновляется раз в 30 секунд и по левому клику. Спящая мышь заряд не отдаёт — тогда остаётся последнее значение.
- Правый клик: «Обновить», «Запускать с Windows», «Проверить обновления», «Выход». Обновление только по кнопке: виджет скачает новую версию с GitHub, проверит подпись автора, подменит себя и перезапустится. Неподписанное или подменённое обновление не ставится.

## Запуск

Скачай `R5BatteryTray.exe` из [Releases](../../releases) и запусти. Установка не нужна.

## Сборка

Нужен [Rust](https://rustup.rs). `build.bat` соберёт и положит `R5BatteryTray.exe` рядом. Тесты: `cargo test`, превью иконки во всех размерах: `cargo test preview -- --ignored` (`preview.bmp`).

Новая версия: поднять `version` в `Cargo.toml` → `build.bat` → `scripts\sign-release.ps1` → тег `v<версия>` → релиз с файлами `R5BatteryTray.exe` и `R5BatteryTray.exe.sig` (именно так, их качает обновлялка). Закрытый ключ лежит в `%USERPROFILE%\.r5batterytrayelease.key`, зашифрованный паролем (скрипт спрашивает его при подписи). Держи копию файла: без него и пароля обновления по кнопке не выпустить.

## Протокол

Feature-report 65 байт на интерфейс VID `373E` / PID `0047` (донгл) или `0046` (провод): запрос `00 00 00 02 02 00 83`, в ответе `[1]=A1`, `[7]` — зарядка, `[8]` — процент. Подсмотрено в [R5BatteryChecker](https://github.com/Xenofff/R5BatteryChecker), [r5-battery-estimator](https://github.com/lferraro1103/r5-battery-estimator) и [attackshark-battery-bridge](https://github.com/maxboeer/attackshark-battery-bridge).
